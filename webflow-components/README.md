# 🦍 Wandering Gorilla - Webflow Component Package

**Vintage Americana Travel Blog Components**

A complete set of custom components for building a vintage 1950s-60s americana aesthetic travel blog in Webflow, with e-commerce and affiliate marketing capabilities.

---

## 📦 What's Included

### Core Components (Ready to Use)

1. **01-site-wide-custom.css** - Complete styling framework
2. **02-hero-section.html** - Vintage photo hero with typewriter effect
3. **03-blog-gallery.html** - Masonry photo gallery with lightbox
4. **04-gear-review.html** - Product review cards with ratings & affiliate links
5. **05-email-signup.html** - Vintage postcard newsletter signup
6. **COMPLETE-SETUP-GUIDE.md** - Full documentation

---

## 🚀 Quick Start

### 5-Minute Setup:

1. Open `COMPLETE-SETUP-GUIDE.md`
2. Follow "Quick Start" section
3. Copy CSS to Webflow Project Settings > Custom Code
4. Add components as Embed elements
5. Publish!
